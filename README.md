# Pearl & Pine Project 🍫

This is an E-Commerce Website for selling chocolates and cookies online.

## 🔧 Technologies Used
- Angular (Frontend)
- ASP.NET Core Web API (Backend)
- SQL Server (Database)
- Razorpay (Payment Integration)
- SMTP (Email OTP Verification)

## 🚀 Features
- User Signup with OTP verification
- Login Authentication
- Product Listing (Home Page)
- Add to Cart
- Checkout with Razorpay Payment
- Order Tracking (My Orders)
- Email Notification System
